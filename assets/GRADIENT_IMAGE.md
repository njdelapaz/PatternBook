# Gradient Image for Weekly Letter

## Required File

**Filename**: `gradient.png`
**Location**: `assets/gradient.png`

## Description

A colorful gradient image used in the weekly letter suggestion card and modal display. Based on the Lightpage design, this should be a warm, inviting gradient.

## Specifications

### Recommended Colors
- **Top**: Pink/Purple (#FF6B9D or similar)
- **Bottom**: Orange/Peach (#FFB347 or similar)
- Creates a warm, sunset-like gradient effect

### Image Dimensions
- **Minimum Width**: 800px
- **Minimum Height**: 400px
- **Aspect Ratio**: 2:1 (horizontal rectangle)
- **Format**: PNG or JPG

### Where It's Used

1. **Suggestion Card** (in scrollable bar)
   - Appears as background at top of card (120px height)
   - Rounded top corners

2. **Modal Display** (full-screen view)
   - Large banner image (200px height)
   - Full width with rounded corners
   - Displays prominently above the letter content

## How to Create

If you don't have the exact Lightpage gradient, you can create one:

1. Use any image editor (Photoshop, Figma, Canva, etc.)
2. Create a gradient from pink/purple to orange/peach
3. Export as PNG at recommended dimensions
4. Save as `gradient.png` in the `assets/` folder

## Alternative

You can also use any warm, inviting gradient image. The exact colors don't have to match perfectly - the goal is to create a welcoming, colorful visual element for the weekly letter.
