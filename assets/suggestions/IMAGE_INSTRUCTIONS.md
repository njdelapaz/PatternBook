# AI Suggestions Image Assets

## Required Image

You need to add one image file to display the artwork suggestion in the demo:

### File: `library-art.jpg`

**Location:** Place this file in `assets/suggestions/`

**Full path:** `assets/suggestions/library-art.jpg`

**Description:** Giuseppe Arcimboldo's "The Librarian" (1526) - A portrait composed entirely of books. This Renaissance painting depicts a human figure made from stacked books, creating a surreal fusion of person and library.

**Where to find:**
- Search for: "Giuseppe Arcimboldo The Librarian"
- Public domain artwork available from Skokloster Castle collection
- Alternative search: "Arcimboldo book portrait"

**Recommended specs:**
- Format: JPG
- Minimum dimensions: 800x1000px (portrait orientation works best)
- Quality: High resolution for clear display on mobile devices

## Why This Artwork?

This artwork directly relates to the first demo note about "wandering through an endless library" where books contain memories. Arcimboldo's surreal composition of a person made from books perfectly mirrors the dream's theme of identity and memory being inseparable from stories and knowledge.

## Alternative

If you can't find the specific Arcimboldo painting, you can use any artwork depicting libraries, books, or surreal library scenes. Just make sure the filename is exactly `library-art.jpg`.
