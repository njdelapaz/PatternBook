# AI Suggestions Image Assets

## Required Image

You need to add one image file to display the artwork suggestion in the demo:

### File: `turtle-lotus.jpg`

**Location:** Place this file in `assets/suggestions/`

**Full path:** `assets/suggestions/turtle-lotus.jpg`

**Description:** An image of "Turtle in a Lotus Pond" artwork. This should be an artwork image depicting a turtle in a lotus pond setting, ideally in a traditional or Asian art style to match the demo theme.

**Recommended specs:**
- Format: JPG
- Minimum dimensions: 800x1000px (portrait orientation works best)
- Quality: High resolution for clear display on mobile devices

## Alternative

If you don't have access to the specific artwork, you can use any placeholder image with a similar theme (nature, animals, traditional art) and the app will display it correctly. Just make sure the filename is exactly `turtle-lotus.jpg`.
